# Problem 17: Decode A Web Page

**Problem link: [here](https://www.practicepython.org/exercise/2014/06/06/17-decode-a-web-page.html)**

## Problem Statement

Note: this is a 4-chili exercise, not because it introduces a concept (although it introduces a new library), but because this exercise is more like a project. Feel free to skip this and come back when you’re more ready!

Use the BeautifulSoup and requests Python packages to print out a list of all the article titles on the [New York Times homepage](https://www.nytimes.com/).


## Example

Output:

```bash
Live
Top Stories
Watch Today’s Videos
More News
The AthleticSports coverage
WirecutterProduct advice
Well
Culture and Lifestyle
AudioPodcasts and narrated articles
GamesDaily puzzles
Site Index
Site Information Navigation
```
